# tethr

ウィンドウやセッションを横断して検索し、目的の作業へ素早く戻るための、Mac向け個人用ツールを設計しています。戻った先で必要なコマンドを、履歴・候補提示・AI補完から見つける体験を目指します。

個人のワークフローに必要な範囲でRaycastの代わりになることを目標に、次を優先します。

- ウィンドウ、tmux、[Herdr](https://herdr.dev/)を横断して探し、目的の作業へ戻る。tmuxとHerdrは同じ第一級の検索・復帰対象として扱う
- 未起動のアプリを開き、起動済みなら前面へ戻す（run-or-raise）
- コマンド履歴・候補・AI補完を使い、日本語でも用事からコマンドを探す

現在はNative・Tauri・OpenTUIの3種類の比較試作があります。採用スタックは未確定です。横断検索や任意セッションへの復帰が完成した製品ではなく、Macでの操作感、入力先の確かさ、失敗を具体的に観測・再検証できることを確認していく段階です。
