# tethr

ターミナルの短い作業をすぐ始め、必要なコマンドを見つけ、出力を次の操作やエージェントへの依頼につなぐための、Mac向け個人用ツールを設計しています。

Ghostty / tmuxを使うワークフローを軸に、次の手間を減らすことを目指します。

- 単発の用事のためにターミナルやコーディングエージェントを開き、作業場所を整える。
- 使いたいアプリを起動する、または起動済みのアプリを前面へ戻す（run-or-raise）。
- コマンドやオプションを思い出す。
- 応答や出力を手でコピーし、次の作業やエージェントへ渡す。

現在はNative・Tauri・OpenTUIの3種類の比較試作があります。採用スタックは未確定で、DeepSeek Harnessとの連携も検討しています。Macでの快適さ、開発の速さ、失敗をLLMへ具体的に返して検証できることを重視します。文章の推敲・翻訳は、ターミナル周りの機能の後に検討する用途です。
